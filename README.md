# Satrafoods - Chuỗi Cửa Hàng Tiện Lợi & Thực Phẩm Tươi Sống

> Hệ thống mua sắm thực phẩm tươi sống an toàn VietGAP, giao nhanh 2 giờ với hơn 180 cửa hàng tại TP.HCM và Cần Thơ.

---

## 1. Tổng Quan Dự Án (Project Overview)

**Satrafoods** là nền tảng thương mại điện tử chuyên cung cấp thực phẩm tươi sống chuẩn VietGAP, OCOP và hàng tiêu dùng thiết yếu trực thuộc **Tổng Công ty Thương mại Sài Gòn (SATRA)**. Dự án được thiết kế và xây dựng theo định hướng giao diện bán lẻ hiện đại kết hợp văn hóa ẩm thực truyền thống Việt Nam, tối ưu hóa trải nghiệm mua sắm trên mọi kích thước màn hình từ điện thoại di động (mobile), máy tính bảng (tablet) đến máy tính để bàn (desktop).

### Triết Lý Thiết Kế: "Gói" (The Metaphor of Care & Packaging)
- **Gói trọn an tâm**: Truy xuất nguồn gốc minh bạch bằng mã QR cho từng mẻ thịt mát, khay rau sạch và thủy hải sản trong ngày.
- **Graphic Minimalism & Constructed Retail Packaging**: Khung viền sắc nét, đường cắt vát 45° mô phỏng tem giá vật lý, phân cấp thông tin rõ ràng và độ tương phản cao đạt chuẩn WCAG AA.
- **Hệ màu nhận diện**:
  - **Brand Green (`#01B341` / `#006E24`)**: Đại diện cho nông sản an toàn, tươi non và nguồn gốc được chứng thực.
  - **Brand Lime (`#DAFF01`)**: Điểm nhấn kích thích thị giác cho các chương trình khuyến mãi, giờ vàng, tag giảm giá và thông báo giỏ hàng.
  - **Neutral Black (`#111111` / `#1C1B1B`)**: Đảm bảo tương phản tuyệt đối trên các nền sáng và màu thương hiệu.

## 2. Tính Năng Chính (Main Features)

1. **Trang Chủ (Home Page)**:
   - Banner chiến dịch quy mô lớn giới thiệu chương trình ưu đãi độc quyền.
   - Khu vực **"Gói Trọn Ưu Đãi Tuần Này"** với đồng hồ đếm ngược (countdown timer) và các gói combo thực phẩm hot.
   - Đăng ký nhận voucher chào mừng 50.000đ dành cho khách hàng mới.
   - Lưới khám phá **18 ngành hàng tiêu dùng** trực quan, phân loại khoa học.
   - **Hệ thống tìm kiếm 180+ cửa hàng Satrafoods** tích hợp lọc theo quận/huyện, hiển thị địa chỉ, hotline và giờ mở cửa.

2. **Trang Danh Mục Sản Phẩm (Category Catalog)**:
   - Danh mục 12 sản phẩm tươi sống tiêu biểu (thịt heo thảo mộc VietGAP, cá hồi Na Uy, bò Úc, rau củ Đà Lạt, set canh chua tiện lợi...).
   - **Bộ lọc đa tiêu chí (Multi-faceted Filtering)**:
     - Phân loại danh mục con (Thịt heo, Bò nhập khẩu, Gia cầm, Thủy hải sản, Rau lá, Củ quả...).
     - Tiêu chuẩn an toàn (VietGAP, GlobalGAP, OCOP 4-5 sao, Organic, Chuỗi ATTP TP.HCM).
     - Khoảng giá (Dưới 50k, 50k - 100k, 100k - 200k, trên 200k).
   - Thanh công cụ sắp xếp: Bán chạy nhất, Phổ biến nhất, Giá tăng/giảm, Ưu đãi tốt nhất.
   - Chế độ xem linh hoạt: Lưới (Grid) hoặc Danh sách (List), phân trang chuẩn e-commerce.

3. **Truy Xuất Nguồn Gốc QR (Provenance & Traceability)**:
   - Mỗi sản phẩm đều có mã kiểm định điện tử, cho phép người dùng xem nguồn gốc trang trại, thời điểm thu hoạch, số lô kiểm định Satra, chỉ số độ tươi (Freshness Score) và cam kết đổi trả 24h.

4. **Giỏ Hàng Thông Minh (Interactive Cart Drawer)**:
   - Thanh tiến trình miễn phí giao hàng (Freeship khi đạt từ 200.000đ).
   - Tự động áp dụng chiết khấu **2% Satra Rewards** cho thành viên thân thiết.
   - Hỗ trợ nhập và kiểm tra mã giảm giá (`SATRAFRESHT3` giảm 30.000đ, `SATRA50K` giảm 50.000đ).
   - Tăng/giảm số lượng sản phẩm nhanh chóng, tính toán lại tổng tiền tức thì.
   - Quy trình đặt hàng giả lập với mã vận đơn tự động.

5. **Tiện Ích & Trải Nghiệm Khách Hàng**:
   - **Satra Rewards Modal**: Thẻ thành viên ảo tích lũy điểm thưởng, tra cứu số điện thoại.
   - **Chọn khu vực giao hàng**: Hỗ trợ chọn nhanh các quận/huyện tại TP.HCM và Cần Thơ để giao siêu tốc trong 2 giờ.
   - **Chân trang chuyên nghiệp**: 4 cam kết vàng về dịch vụ, thông tin pháp lý đơn vị chủ quản SATRA, số tổng đài miễn cước 1800 1199 và liên kết chính sách bảo mật/đổi trả.

## 5. Hướng Dẫn Cài Đặt (Installation Instructions)

### Yêu Cầu Tiên Quyết (Prerequisites)
- **Node.js**: Phiên bản 18.x trở lên (khuyến nghị Node.js 20 LTS hoặc 22 LTS).
- **Trình quản lý gói**: `npm` (mặc định đi kèm Node.js) hoặc `pnpm` / `bun`.

### Các Bước Cài Đặt
1. **Clone repository:**
   ```bash
   git clone https://github.com/myapah76/satrafood.git
   cd satrafoods
   ```

2. **Cài đặt các gói phụ thuộc (Dependencies):**
   ```bash
   npm install
   ```

## 6. Hướng Dẫn Phát Triển (Local Development)

Chạy môi trường phát triển với tính năng Hot Module Replacement (HMR):
```bash
npm run dev
```
Sau khi khởi động, ứng dụng sẽ có sẵn tại:
- **Local:** `http://localhost:3000`
- **Network:** `http://<ip-mạng-nội-bộ>:3000`

---

## 7. Đóng Gói Và Triển Khai (Build & Production)

1. **Kiểm tra kiểu dữ liệu tĩnh:**
   ```bash
   npm run lint
   ```

2. **Chạy bộ kiểm thử tự động:**
   ```bash
   npm test
   ```

3. **Đóng gói mã nguồn cho môi trường Production:**
   ```bash
   npm run build
   ```
   Thư mục đầu ra `dist/` chứa toàn bộ HTML, CSS và JavaScript đã được tối ưu hóa, nén gzip sẵn sàng để triển khai lên Vercel, Netlify, Cloudflare Pages hoặc máy chủ Nginx.

4. **Xem trước bản đóng gói cục bộ:**
   ```bash
   npm run preview
   ```

## 8. Cấu Hình Môi Trường (Environment Configuration)

Dự án có thể chạy trực tiếp mà không bắt buộc phải có biến môi trường đặc thù cho giao diện frontend cơ bản. Đối với các tích hợp mở rộng:

Tạo tệp `.env` hoặc `.env.local` tại thư mục gốc:
```env
# Cổng chạy ứng dụng khi phát triển (tùy chọn, mặc định 3000)
PORT=3000

# Khóa Gemini API nếu sử dụng trợ lý mua sắm AI (tùy chọn)
GEMINI_API_KEY=your_gemini_api_key_here
```

## 9. Danh Sách Lệnh Khả Dụng (Available Scripts)

| Lệnh | Mô tả |
|---|---|
| `npm run dev` | Khởi động máy chủ phát triển Vite tại cổng 3000 |
| `npm run build` | Biên dịch TypeScript và đóng gói ứng dụng vào thư mục `dist/` |
| `npm run preview` | Xem trước bản build production tại máy cục bộ |
| `npm test` | Chạy bộ kiểm thử đơn vị với Node.js test runner |
| `npm run lint` | Kiểm tra tính hợp lệ của toàn bộ kiểu TypeScript (`tsc --noEmit`) |
| `npm run clean` | Xóa sạch thư mục `dist/` và file build tạm |
